# ⛩️ 동양사상입문 스마트 훈련소 (Web App)

## 📌 주요 기능
1. **🎯 1개념 콤보 훈련 (Multi-Angle Practice)**:
   - 한 개념당 3~4개의 연속 변주(자형 팩트 OX ➔ 출제 함정 파쇄 ➔ 핵심 키워드 직접 입력)를 풀어 개념을 360도로 완전 정복합니다.
2. **✍️ 직접 타이핑 모드 (Cloze Mode)**:
   - 모바일 키보드로 핵심 키워드를 직접 입력하여 인출(Active Recall) 훈련을 수행합니다.
3. **📝 노션 스타일 터치 토글 (Notion Accordion)**:
   - 폰 화면에서 터치하여 개념 요약 및 변주별 정답을 펼쳐볼 수 있는 단권화 뷰입니다.

## 🚀 GitHub Pages 1분 무료 배포 가이드
1. GitHub(github.com)에서 새 Public 저장소 생성 (`dongyang-study`)
2. `app` 폴더 내 파일들(`index.html`, `styles.css`, `app.js`, `quiz_data.json`)을 업로드
3. 저장소 **Settings ➔ Pages ➔ Branch: main** 선택 후 Save
4. 1~2분 뒤 생성되는 `https://<아이디>.github.io/dongyang-study/`로 스마트폰에서 접속 후 **[홈 화면에 추가]**!
